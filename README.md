# Pata Amiga

Exemplo de portfólio de pet shop · banho & tosa. Marca fictícia, fotos geradas e preços ilustrativos em reais.

Catálogo com filtros, detalhes, seleção de serviços e resumo demonstrativo. Nenhum agendamento, pedido, pagamento ou contato real é enviado. Sem armazenamento persistente.

## Executar
```sh
bun install
bun run dev
```
## Testar
```sh
bun run test
```

React 19, TanStack Start e Tailwind CSS. Substitua a marca e conecte canais reais antes do uso comercial.
